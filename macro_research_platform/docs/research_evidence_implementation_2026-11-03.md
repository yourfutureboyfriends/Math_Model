# Research roadmap implementation — 3 November 2026

Open **Markets → Research desk (RDESK) → Open evidence tools**. Existing Connected investment workflows remain available alongside the new workbench. Tools respect the existing signed-in account, fund and role. No new subscription, account permission, external message, trade or enabled monitoring schedule was created.

## Implemented capabilities and boundaries

| Roadmap area | Implemented | Boundary |
|---|---|---|
| Reproducible observations | Server-generated canonical payload checksums, input IDs, receipt timestamps, provider metadata, missing-data flags and valuation model fingerprints. New revisions retain earlier payloads. Current records are capped at 50 MB and immutable history at 100 MB per account/fund. | Integrity is not independent provider verification. These are canonical JSON captures, not byte-identical HTTP response archives. Legacy captures are not retroactively certified. |
| Historical availability | Read the latest saved version known by a timezone-qualified server receipt cutoff. Imported publication/observation dates cannot backdate availability. | Conservative server-observed history, not a recovered historical consensus feed. |
| Offline replay | Checksummed, versioned FCFF projection arithmetic replay with saved discount factors, terminal value and equity/listing-unit bridge; no provider calls. | Does not rerun archived original forecasting code, rebuild sensitivities or replay other model types. A fingerprint identifies the captured code; an executable historic model bundle is not archived. |
| Security continuity | Existing listing resolution now exposes dated issuer/share-class links. Administrator assertions retain evidence, author, identifiers and non-overlapping effective intervals. Direct exposures can aggregate by explicitly linked issuer without dropping real holdings. | Manual reference assertions are not a complete provider-verified global security master. Aliases remain explicit; no name-similarity merges. |
| Corporate actions | Append-only reference ledger for splits, ADR ratios, ticker changes and delistings, linked to a persistent listing ID, with source evidence and author. | Does not apply another split factor to provider-adjusted histories or change holdings. It is reference evidence, not an automated corporate-action booking engine or complete historical constituent service. |
| Data reconciliation | Source comparisons require matching field, period, observation date, currency, units and accounting basis. Disagreements and tolerances are explicit; both source inputs are retained when saved. Capture coverage counts missing metadata and legacy envelopes. | No automatic provider replacement. Different names do not establish independent sourcing. Population-wide automatic field reconciliation needs source adapters and mapped accounting facts. |
| Estimates | Existing opt-in scheduler continues to capture estimates/filings. Prospective histories match EPS/revenue by explicit fiscal end and currency, never relative 0q/0y labels alone. Sourced JSON observation imports can supply fiscal identity. Monitor inbox events retain new filing URLs, capture references and matched revisions. | Existing providers may omit fiscal-end identities; those rows remain unmatched. No licensed historical broker consensus was added. Monitoring remains disabled unless explicitly configured in the existing UI. |
| Valuation explanation | Exact Shapley allocation across seven captured FCFF driver groups, plus existing ordered substitution. Contributions reconcile to the saved value change and Shapley allocation is symmetric under reversal. | Allocation of mathematical interactions is not causal attribution. Terminal discount effects remain in the terminal group; share count/FX/listing conversion remain grouped. |
| Forecast evaluation | Import continuous forecasts/outcomes and naive baselines; reject future outcomes, training after issue, duplicate rows, missing currency/evidence and invalid values. Group MAE, RMSE and baseline-relative MSE skill by model, target, region, sector, currency and horizon. | Supplied timestamps do not independently prove genuine out-of-sample training. No calibrated confidence interval or automatic trading/model re-fit is implied. |
| Tracker events | On-demand GFW port-visit, loitering and AIS-gap samples (90-day UI default, at most 100 events). Source/dataset, retrieval date and truncation are visible. Import documented vessel/port/route/airport/airline events and reported passenger/freight/flight metrics with units; supply a company relationship and source URL. | Existing GFW token and dataset access are required. No direct EUROCONTROL/BTS downloader or global manifest feed was installed. Reported statistics can be imported; receiver counts/capacity are not actual throughput. Gaps do not establish intent. |
| Execution evidence | Actual supplied timestamped prints produce sample VWAP; compare fill versus arrival/VWAP; add explicit fees and dated FX for base-currency costs. Reject prints outside the declared window and future/stale FX evidence. Missing fees/FX leave total costs unavailable. Saved evaluations retain their inputs and result. | Supplied prints are not necessarily consolidated market volume; spread/impact components are not inferred. A licensed intraday feed is not installed. |
| Existing TCA | Replaces latest FX conversion with historical daily FX dated on/before the fill session (maximum four calendar days old); preserves quote minor units; withholds FX when quote currency/units are unknown. Adds per-fill FX/basis fields, correct even-sample median and known-versus-incomplete cost coverage. | Daily FX closing marks can differ from execution-time FX. Existing HLC/3 benchmark remains clearly labelled a typical-price proxy, not actual VWAP. |
| Research inbox | Captured source changes and analyst-linked tracker events display source/capture evidence and known direct exposure. Reviewed/dismissed/unreviewed transitions are optimistic and account/fund-scoped, with append-only review history. Dated issuer exposure aggregation exposes unmapped holdings. | No causal price-impact claim or inferred private flow. No outbound notifications or automatic trades. |

## UI and use

The evidence workbench includes Inbox, Capture audit, Estimate history, Import observation, Compare sources, Tracker evidence, Execution evidence, Value validation, Corporate events and Identity links. JSON templates are labelled illustrative; users replace them with sourced observations or import a bounded JSON file. Administrative reference writes remain disabled for other roles; history is readable through the existing research access controls.

The valuation bridge method selector is in Connected tools → Valuation bridge. Vessel activity is loaded only when requested from a ship detail card. Existing TCA links to the execution-evidence tool and exposes historical FX/basis details in tooltips.

## Validation

New regression tests cover forged client envelopes, historical receipt cutoffs, replay checksums, Shapley symmetry/reconciliation, mismatched source bases, fiscal rollover, overlapping identity links, issuer exposure totals, tenant isolation, optimistic inbox reviews, future/look-ahead outcomes, sample VWAP, absent fees, historical FX, bounded vessel events, capture coverage and immutable corporate events. HTTP tests use temporary databases and test accounts, not the user's production research records.

The full frontend suite initially exposed a missing-counts crash in Alpha Lab's signal-health panel; the panel now tolerates absent summary counts. Validation passed: 64 backend tests, 536 frontend tests across 61 files, a further 10 focused component tests after the final UI additions, and the TypeScript/production build. The build retains a warning about large bundles. Additional regressions reject future tracker events and withhold historical FX when quote currency is absent.

Browser verification reached the app's sign-in screen. No credentials were guessed and no authentication bypass was introduced; populated authenticated UI behavior is covered by component and HTTP tests rather than claimed as a completed visual inspection.

## Remaining work requiring more data or a separate model-archival implementation

- Licensed historical consensus, international comparable filings and complete dated corporate-action/constituent coverage.
- Original forecasting-code/dependency archives and full offline reruns for all valuation and macro models.
- Automatic official-source reconciliation adapters, broader reported aviation statistics ingestion and independently sourced issuer/route relationships.
- Independently verified security-master mappings and entitled full-market intraday execution data.

These boundaries are explicit in the tool results and UI. Missing coverage is not filled with manufactured history, hidden-flow scores or inferred actual cargo.
