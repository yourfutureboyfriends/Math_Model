# Markets page and internal-view audit — 29 October 2026

## Scope and evidence

The inventory maps **all 94 registered Markets functions**, including 28 instrument functions, through their route bodies and transitive local components. It inspected 50 source files, including the shared price chart. There are no unmapped registered functions. Internal components, static panel/control labels, data endpoints and review signals are recorded in `markets_page_inventory_2026-10-29.json`. The inventory is generated by `frontend/scripts/audit-markets.mjs`.

This is a UI, navigation, accessibility and client request-lifecycle audit. Static component coverage and automated state tests are distinguished from browser verification. It does not certify every live provider response, every populated internal-tab interaction, or the financial correctness of every model.

## Verification and limits

- Automated page-state coverage: **187 checks** — 93 single-function bodies in pending and unavailable-feed states, plus malformed saved launchpad recovery. These mount real page components with controlled requests; they do not claim populated-data coverage for every inner tab.
- Shared regression tests cover request cancellation, URL switching, stale-data preservation/retry, overlapping polls, keyboard sorting and preserving inputs when panels collapse.
- Additional checks cover globe polygon areas/ocean points, exchange metadata/label collisions, sound-on embeds, sidebar search, fund identities, collapsed PE navigation and malformed international-instrument links.
- Browser verification used a temporary harness of the actual MarketsPage and sidebar with existing public local API feeds, without changing server authentication. World markets data, comfortable/compact density, the table explorer, 3D globe, Tokyo exchange focus/reset and console output were checked. Temporary preview source is removed after verification.
- Authenticated watchlist edits, saved journal/alert mutations, private fund-logo fetches and full live-coverage audio playback were not exercised in that public-feed browser session. Unit tests cover their UI/default configuration where described; the server access rules remain in force.
- Financial calculations and external source quality were not re-certified by this UI audit. Backend/provider delays and errors remain possible and are surfaced rather than replaced with fabricated data.
- Existing production bundle-size warnings remain. The globe now retains original detail (80,617 topology vertices); the earlier 21,052-vertex simplification was removed because collapsed tiny rings could fill the ocean. Performance relies on cached 2D paths, demand-driven canvas rendering, visibility pausing and coalesced interactions. No device-specific FPS claim is made.

## Reproduce

Run `node frontend/scripts/audit-markets.mjs` from the platform directory. From `frontend`, run `npx tsc --noEmit`, `npx vitest run` (local API required by existing integration tests), and `npx vite build --outDir /tmp/markets-audit-build`. Final verification: TypeScript passed; **308 tests across 31 files passed**; production build passed. Vite still warns about pre-existing large chunks (MarketsPage approximately 707 kB before gzip).


## Inner-page modernisation follow-up

The second pass changes page composition rather than only the sidebar or function tabs. The page canvas applies to all 94 registered functions and their inner view components:

- 51 existing control groups now use consistent filter/action surfaces with clearer spacing and focus treatment.
- 47 existing chart instances now sit in responsive chart surfaces; their plots, units and calculations remain unchanged.
- Four existing KPI/stat component definitions were modernised, affecting their repeated uses throughout volatility, economic data and event screens.
- Long pages build a local “On this page” outline from their actual sections, including sections revealed by inner tabs. Navigation scrolls and focuses the relevant heading; compact launchpad panes omit it to conserve room. The observer batches updates and disconnects on unmount.
- Movers gain displayed-sample summaries (count, median move, rising/falling counts). Labels explicitly distinguish the displayed list from market-wide breadth.
- The equity screener gains a roomier filter grid, current-page company search, range validation, richer empty states and an explicit pending-filter notice. Edited controls no longer look as though they have already changed the displayed results.
- Added regression checks for pending vs applied filters, reversed ranges, local row search and section navigation/focus. Existing registered-page loading/unavailable-state checks continue to run.

Browser verification exercised the actual screener using public local API data, including its loaded results and local company search. Screenshot: `/tmp/markets-screener-modern.jpg`. The temporary visual harness was removed. Other live-provider/authenticated interaction limits stated above still apply. Both modern and classic skins retain the same routes and financial workflows.
